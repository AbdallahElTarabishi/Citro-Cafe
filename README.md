## ✨ المميزات المحدثة:
1. **فصل الكود بشكل احترافي**: فصل الـ HTML والـ CSS والـ JS لسهولة التطوير والتعديل مستقبلاً.
2. **باسورد الأدمن**:
   - الباسورد الافتراضي: **`18293`**.
   - وجود أيقونة العين 👁️ لإظهار وإخفاء الباسورد أثناء كتابته للتأكد منه.
   - خيار لتغيير الباسورد من داخل لوحة الأدمن مع زر **«حفظ فوري»**.
3. **حل مشكلة الزووم في الآيفون (iOS Safari)**:
   - منع الزووم التلقائي عند النقر المتكرر لفتح لوحة الأدمن (`touch-action: manipulation`).
   - ضبط حجم خط المدخلات لـ `16px` لمنع قفز وتكبير الشاشة عند لمس الحقول.
4. **InstaPay & IPA**:
   - مسح كافة روابط التيست القديمة.
   - إمكانية وضع رابط الدفع وعنوان IPA وحفظهما فوراً.
5. **شبكة الواي فاي**:
   - حفظ فوري لاسم الشبكة والباسورد وتحديث رمز الـ QR Code في اللحظة نفسها.
6. **قاعدة البيانات السحابية الأونلاين (Realtime Cloud Sync)**:
   - مدمج مع **Firebase Realtime Database**.
   - أي تعديل يجريه صاحب الكافيه من تليفونه يسمّع فوراً عند كل الزوار دون الحاجة لتحديث الصفحة.
   - في حال عدم تفعيل السحابة، يعمل النظام تلقائياً وبأمان عبر التخزين المحلي السريع (`localStorage`).
